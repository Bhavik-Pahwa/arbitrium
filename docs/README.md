# Documentation

This folder keeps non-runtime material out of the project root.

## Contents

```text
project/           PRD, implementation checklist, sprint notes, and project reference
review/screenshots Visual QA screenshots and captured review frames
reference/assets   Original design-generation inputs and reference media
reference/          Imported prompt/template guidance used during prototyping
archive/           Original zipped reference packages
```

The runtime application lives in `backend/`, `frontend/`, and `ai_engine/`.
